## 📖 About
 
**[Markdown Online Viewer](https://markdownonlineviewer.com/)** is a free web-based tool for writing, previewing, and reading Markdown (`.md`) content. Paste or type your Markdown on one side and see the formatted result instantly on the other. No installation, no sign-up, no distractions.
 
Whether you are drafting a GitHub `README.md`, writing documentation, taking notes, or just checking how a Markdown file will look, [Markdown Online Viewer](https://markdownonlineviewer.com/) gives you a quick and clean way to do it.
